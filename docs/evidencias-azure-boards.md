# Evidências - Azure Boards

## Link do Projeto

https://dev.azure.com/RM561052/Pedix-Compliance-QA

## Objetivo

O Azure Boards foi utilizado para organizar o planejamento dos testes manuais da aplicação Pedix API.

## Estrutura Planejada

A estrutura de testes manuais contempla:

- Test Plan;
- Test Suites;
- Casos de teste;
- Dados de entrada controlados;
- Dados de saída esperados;
- Procedimentos de execução.

## Funcionalidades Cobertas

Os testes manuais contemplam as principais funcionalidades do sistema:

- Health Check das APIs;
- Login e autenticação;
- Clientes;
- Mesas;
- Comandas;
- Pedidos;
- Itens de pedido;
- Pagamentos;
- Categorias;
- Cardápio;
- Avaliações;
- Relatórios.

## Observação de Acesso

O professor deve estar adicionado como membro da organização/projeto no Azure DevOps para conseguir acessar e corrigir os testes manuais.
